# simple-interest-calculator


A simple tool to calculate interest on loans or investments based on principal, rate, and time.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal Amount
- **R** = Annual Interest Rate (%)
- **T** = Time Period (Years)

## Features
- Calculates interest instantly
- Gives total amount payable/receivable
- Clear and simple documentation

## How to Run
1. Input the principal amount.
2. Input the annual interest rate.
3. Input the time duration in years.
4. Calculate simple interest.
